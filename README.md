# MoralVector v2

가상 딜레마에서의 선택 패턴을 관계별로 비교하고, 14개 행동 스펙트럼으로 시각화하는 브라우저 기반 시뮬레이터입니다.

## 주요 기능

- 60개 가상 딜레마 문항 은행
- 5 / 10 / 20 / 40 / 60문항 진단 모드
- 동료·내 사람 / 무관한 타인 / 경쟁자 / 원수·배신자 / 조직 상황을 균형 있게 샘플링
- 14개 스펙트럼 점수 계산
- 관계 변화에 따른 보복성 곡선
- 레이더 차트 기반 행동 벡터 시각화
- 결과 아키타입 및 관계별 요약
- 브라우저 인쇄 / PDF 저장
- 별도 백엔드 없이 정적 배포 가능

## 구조

```text
moralvector/
├─ index.html
├─ css/
│  └─ style.css
└─ js/
   ├─ dilemmas-1.js   # 01–15
   ├─ dilemmas-2.js   # 16–30
   ├─ dilemmas-3.js   # 31–45
   ├─ dilemmas-4.js   # 46–60
   └─ app.js          # 진행 상태, 점수 계산, 결과 및 차트
```

## 사용 기술

- HTML / CSS / Vanilla JavaScript
- Tailwind CSS CDN
- Chart.js
- Font Awesome
- Google Fonts (Noto Sans KR, Fira Code)

## 점수 축

인지적 공감, 정서적 공감, 목표 지향성, 선택적 충성심, 보편적 이타성, 저비용 이타성, 도구적 인간관계, 마키아벨리즘, 무관한 타인 가학성, 경쟁자 대상 가학성, 원수 대상 가학·보복성, 통제 욕구, 절차적 공정성, 도덕적 배제 위험성.

## 주의

MoralVector의 결과는 가상 시나리오에 대한 선택을 요약한 자기이해·창작·엔터테인먼트용 시각화이며, 심리학적·의학적 진단이나 실제 행동 예측 도구가 아닙니다.
